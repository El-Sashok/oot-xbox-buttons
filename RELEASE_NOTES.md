Xbox buttons for Ocarina of Time on Lichii.

- Action button cross in the Xbox layout: Y top, X left, A bottom, B right.
- LB, RB, LT, RT, Menu and View icons.

Requires a Lichii build with [PR #203](https://github.com/zortos293/Lichii/pull/203). See the [install procedure](https://github.com/El-Sashok/oot-xbox-buttons#installation).

These installers contain no game files: they build the mod from your own copy of the game. The Windows installer has not been tested with the game yet.
